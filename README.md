# MachineLearningModels (In progress posting soon)
Python implementations of Machine Learning algorithms and evaluation pipelines

This repository contains my implementations and experiments from a Machine Learning course:
- Dimensionality reduction: PCA, LDA
- Generative classifiers: MVG / Naive Bayes / Tied MVG
- Discriminative models: Logistic Regression, SVM (RBF)
- GMM models
- Evaluation: confusion matrices, calibration, (min/act) DCF, Bayes risk
